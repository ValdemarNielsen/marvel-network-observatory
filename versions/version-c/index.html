    What surprised us

    “Spider-Man is a destination. Betsy Braddock is a guide.”

    Spider-Man receives 106 links, more than a third of all other pages, but sends only nine. Betsy Braddock sends 28, the network maximum, while receiving seven.

    Direction changes the meaning of importance. In-degree captures prominence across the selected Wikipedia universe; out-degree also reflects how broadly an article introduces readers to other characters.

    How we built it

    Reproducible, frozen, and directed.
