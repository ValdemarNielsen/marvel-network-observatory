04 The verdict

Hubs explain some triangles.
They do not explain Marvel.

The paragraph we would put in a paper

The undirected Marvel giant component has average clustering C = 0.320. Across 100 degree-preserving rewires with 10m successful edge swaps each, mean clustering was 0.154 (SD = 0.0099; z = 16.8; one-sided empirical p = 1/101 = 0.0099). The degree sequence therefore explains part, but not all, of Marvel's clustering; additional organization in who links to whom is required, although this test does not identify one unique mechanism.

We can say

Degrees alone fall short.

The real value is above every exact-degree shuffle. Something about the placement of links creates extra closed neighborhoods.

We cannot say

We found the cause.

Communities, editorial conventions, shared storylines, and other structures could all contribute. The test rejects a baseline, not every alternative.

What surprised us

Pure chance gives C = 0.038. Keeping the hubs raises that to 0.154. Reality then doubles it again to 0.320.

05 The receipts

Reproducible.
Preselected. Honest.

We chose average clustering before running the nulls and used the same frozen network as Issue 01.

  1. 01

    Choose the graph

    Collapse directed links to undirected pairs, then use the 277-character giant component with 1,421 links.

  2. 02

    Build the nulls

    Generate 100 networks for each baseline with fixed seed 20260909.

  3. 03

    Mix thoroughly

    Each degree-preserving null receives 14,210 successful swaps, exactly ten times the link count.

  4. 04

    Verify the promise

    Sort and compare every shuffled degree sequence with the original. All 100 matched exactly.

  5. 05

    Never report p = 0

    Use (1 + extreme nulls) / (1 + simulations). With 100 simulations, the smallest possible value is 1/101.
